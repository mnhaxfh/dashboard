# Hospital Dashboard

Dự án demo dashboard vận hành khám bệnh.
- backend/: FastAPI
- frontend/: Flutter
- data/: dữ liệu dùng chung (seed, mẫu)
- docs/: tài liệu, sơ đồ, demo HTML tham chiếu

chạy backend: uvicorn main:app --reload --port 8000
chạy frontend: flutter run
